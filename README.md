## ✨ Recursos Sincronizados com o Aplicativo

### 🎀 AURA — Assistente IA Integrada
Sua assistente inteligente diretamente conectada ao painel lateral do aplicativo.
- 💬 **Painel Dedicado** — Espaço lateral pronto para processar comandos e analisar os arquivos enviados.
- ⚡ **Ações Rápidas** — Ativação instantânea através do botão **AURA IA** no cabeçalho do sistema.
- 🔍 **Monitoramento Biométrico** — Preparada para monitorar traços biométricos e automações com a biblioteca `face-api.js` ativada.

### 🤖 BOT PLUS — Organizador Neural & Automação
Robô auxiliar integrado para o gerenciamento avançado do cofre de arquivos:
- 🚀 **Executar Otimização** — Botão mestre no painel lateral para rodar a inteligência analítica sobre os arquivos locais.
- ⚙️ **BOT PLUS Dedicado** — Acesso rápido no menu superior do cabeçalho para gerenciar diretrizes do robô.
- 📊 **Logs do Sistema** — Histórico técnico acessível em tempo real para visualizar o andamento operacional.

### ⚡ Telemetria HUD & Status
- **Status do Sistema** — Monitoramento contínuo exibindo o status operacional com a Aura IA conectada.
- **Contador de Arquivos** — Contador dinâmico registrando o total de arquivos processados e novas adições diárias.
- **Latência do Bot** — Exibição técnica de latência ultrabaixa (24ms) para respostas em tempo real.
- **Barra de Armazenamento** — Pílula visual no cabeçalho que exibe a porcentagem exata de espaço consumido pelo banco de dados.

### 🛡️ Cofre de Arquivos & Ferramentas
- **Filtros Rápidos** — Abas de categorização instantânea separadas por: *Todos • Imagens • Documentos • Zips*.
- **Busca & Ordenação** — Entrada de texto inteligente para localizar arquivos ou comandos, com menu de classificação por *Recentes, Nome (A-Z) e Tamanho*.
- **Área Dropzone** — Interface drag-and-drop intuitiva com suporte a clique para upload imediato de arquivos.
- **Persistência em Nuvem** — Botão dedicado para envio rápido e backup externo do cofre de arquivos.

### 🎨 Design Glassmorphism Avançado
- **Estética Cyber-Dark** — Layout escuro refinado construído com efeitos de blur (`backdrop-filter`), brilhos radiais neon e bordas sutis de alta tecnologia.
- **Responsividade Nativa** — Grid inteligente que se adapta perfeitamente de telas de smartphones a monitores desktops de até 1400px de largura máxima.

## 🌐 Quando Precisa de Internet?

| Operação | Precisa de Internet? |
|---|:---:|
| Abrir pela 1ª vez | ✅ Sim (carrega fontes e as bibliotecas JSZip e face-api.js via CDN) |
| Uso diário (Adicionar e gerenciar arquivos) | ❌ Não — 100% offline |
| Filtros e Busca de Arquivos | ❌ Não — processamento estritamente local |
| Executar Otimizações e Ler Logs | ❌ Não |
| Reconhecer Rostos com face-api.js (1ª vez) | ✅ Sim (baixa os modelos neurais para o cache do navegador) |
