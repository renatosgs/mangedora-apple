🔗 Google Fotos (OAuth 2.0)

Não configurado
Por que preciso de um Client ID? O Google proíbe que aplicativos peçam e-mail/senha diretamente (é proteção contra golpes). Cada app usa o próprio OAuth Client ID — público, gratuito e você mesmo cria em 5 minutos.

Passo a passo:
1. Acesse console.cloud.google.com
2. Crie um projeto → APIs e serviços → Biblioteca → ative Photos Picker API
3. Tela de permissão OAuth → tipo Externo → adicione seu e-mail como testador
4. Credenciais → Criar → ID do cliente OAuth → Aplicativo da Web
5. Em Origens JavaScript autorizadas, adicione http://localhost e/ou seu domínio
6. Copie o Client ID e cole abaixo
